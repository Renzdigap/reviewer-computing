# ⏱️ Hour 04: User, Group & File Permission Management
**Pillar:** HCIA-openEuler V2.0 (Operating System & Cloud-Native iSula)  
**Official Material Reference:** Chapter 04 Part 1 (pp. 154–193)  
**Pacing:** 60 Minutes (4 × 15-Minute Active Learning Sprints)

Master Linux multi-user UID/GID architecture and configuration files (`/etc/passwd`, `/etc/group`, `/etc/shadow`), manage accounts and password aging (`useradd`, `usermod`, `userdel`, `passwd`, `chage`, `gpasswd`), configure `rwx` permissions, ownership, and `umask` (`chmod`, `chown`, `chgrp`), and implement Sticky Bit, fine-grained ACLs (`getfacl`, `setfacl`, `chacl`), and privilege escalation (`su`, `sudo`).
