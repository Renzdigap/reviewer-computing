# ⏱️ Hour 03: Vim Editor & Text Processing Utilities
**Pillar:** HCIA-openEuler V2.0 (Operating System & Cloud-Native iSula)  
**Official Material Reference:** Chapter 03 Part 2 (pp. 118–153)  
**Pacing:** 60 Minutes (4 × 15-Minute Active Learning Sprints)

Master the Vi/Vim text editor across Normal, Insert, Visual, and Command-line modes, view and extract files with `cat`, `more`, `less`, `head`, and `tail`, slice and filter text with `cut`, `grep`, `wc`, `sort`, `diff`, and `tr`, and automate stream processing with `awk` and `sed`.
