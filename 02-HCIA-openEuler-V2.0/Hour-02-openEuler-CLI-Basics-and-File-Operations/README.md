# Hour 02: openEuler CLI Basics & File Operations
**Pillar:** HCIA-openEuler V2.0 (Operating System & Cloud-Native iSula)  
**Official Material Reference:** Chapter 03 Part 1 (pp. 55–117)  
**Pacing:** 60 Minutes (4 × 15-Minute Active Learning Sprints)

Master Linux command syntax, the 9 manual (`man`) sections, session and power management commands, the Linux Filesystem Hierarchy Standard (FHS), directory navigation (`pwd`, `cd`, `ls`), file lifecycle operations (`mkdir`, `touch`, `cp`, `mv`, `rm`), file searching (`find`, `locate`, `which`), archiving/compression (`gzip`, `tar`), and hard vs. symbolic links (`ln`).
