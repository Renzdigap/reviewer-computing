Hands-On Lab: Searching Stale Logs, Packing .tar.gz Archives & Testing Links

PRACTICAL LAB SCENARIO

You need to locate all regular files in /var/log/anaconda/ modified more than 7 days ago, pack all .log files in the current directory into log.tar.gz and extract them into ./log/, and create both a hard link (link_h_password) and a soft link (link_s_password) to passwd.

Instructions

  • 1Step 1: Search /var/log/anaconda/ for regular files (-type f) with modification time earlier than 7 days (-mtime +7) using find.
  • 2Step 2: Pack and compress .log into log.tar.gz using tar -zcf log.tar.gz .log and extract it to ./log/ using tar -zxf log.tar.gz -C ./log/.
  • 3Step 3: Create a hard link ln passwd link_h_password and a soft link ln -s passwd link_s_password.
