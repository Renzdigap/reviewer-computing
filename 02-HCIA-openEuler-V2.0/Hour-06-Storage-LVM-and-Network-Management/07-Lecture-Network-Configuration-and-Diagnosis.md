### 1. Querying Network State, Routes & Hostnames
* **Viewing IP, Gateway & DNS:**
  * **IP & Mask:** **`ip addr`** or **`ifconfig`**.
  * **Gateway & Routing Table:** **`ip route show`** or **`route -n`**.
  * **Official Ch.05 Quiz Q1 Rule:** The **`route`** command can view or configure host route information, **but routes configured via the `route` command are TEMPORARY and do NOT remain valid permanently after a reboot!**
  * **DNS Server:** **`cat /etc/resolv.conf`** (generated by NetworkManager; `nameserver <IP>`).
* **Setting the System Hostname (3 Methods — Ch.05, p.305):**
  1. **Temporary (until next restart):** **`hostname new-name`**
  2. **Permanent (CLI):** **`hostnamectl set-hostname new-name`** (or via `nmtui`)
  3. **Permanent (Config file):** Write the new name to **`/etc/hostname`**.

---

### 2. Predictable NIC Naming Rules & `ifcfg-*` Files
openEuler uses `systemd/udev` **Predictable Network Interface Names** (e.g., **`enp0s3`**, **`wlp3s0`**; falls back to **`eth0`** if rules cannot be applied):
* **2-Letter Type Prefix:** **`en`** (Ethernet), **`wl`** (Wireless LAN / Wi-Fi), **`ww`** (WWAN).
* **Location/Hardware Scheme:**
  * **`p<bus>s<slot>`**: PCIe slot (`p0s3`).
  * **`o<index>`**: Onboard integrated NIC (`o1`).
  * **`s<slot>[f<func>]`**: Hot-swappable slot / SR-IOV virtual function (`s0f1`).
  * **`x<MAC>`**: MAC address-based (`x78e7d1`).
  * **`u<port>`**: USB device port (`u2`).
* **Config Files (`/etc/sysconfig/network-scripts/ifcfg-*`):** Key parameters: `TYPE`, `BOOTPROTO` (`dhcp`/`static`/`none`), `ONBOOT` (`yes`/`no`), `IPADDR`, `NETMASK`, `GATEWAY`, `BROADCAST`, `HWADDR`/`MACADDR`, `PEERDNS`, `DNS1`/`DNS2`, `USERCTL`, `NAME`, `DEVICE`. *(Note: In kernel 3.x+, Huawei recommends **`nmcli`** or **`nmtui`** over manual `ifcfg-*` editing).*

### 3. NetworkManager (`nmcli` & `nmtui`) and Network Diagnosis (`ping`, `tracepath`, `ss`)
* **Device vs. Connection:** A **Device** is a physical/virtual NIC (`enp4s0`); a **Connection** is a configuration profile. **A device can have multiple connections, but only ONE connection can be active on a device at a time!**
* **`nmcli` Core Commands:**
  * Show connections: **`nmcli connection show [--active]`**
  * Add DHCP connection: **`nmcli connection add con-name 'Demo' type Ethernet ifname enp4s0`**
  * Add Static IP connection: `nmcli con add type ethernet con-name my-eth ifname eth0 ip4 192.168.1.100/24 gw4 192.168.1.1`
  * Modify DNS / Add secondary DNS (`+`/`-`): **`nmcli con mod 'Demo' ipv4.dns 192.168.100.250`** and **`nmcli con mod "Euler" +ipv4.dns 114.114.114.114`**
  * Configure Static Route: **`nmcli connection modify enp3s0 +ipv4.routes "192.168.122.0/24 10.10.10.1"`** (or interactive `nmcli con edit`)
  * Activate connection (required for modifications to take effect!): **`nmcli connection up 'Demo'`**
* **`nmtui`:** Text-based curses GUI with 3 main actions: *Edit a connection*, *Activate a connection*, *Set system hostname*.
* **Network Diagnosis Utilities:**
  * **`ping`**: Sends **ICMP echo request** packets and waits for echo replies to test connectivity.
  * **`tracepath`**: Traces packet path from source to destination: (1) hop count/routing nodes, (2) RTT of each hop, (3) **detects Path MTU (`pmtu`) changes**.
  * **`ss` (Socket Statistics, e.g., `ss -talnp`)**: Displays network sockets/listening ports; **works faster than `netstat` by accessing data directly from the kernel!**

---

## Key Takeaways
- **Routes configured with the 'route' command are temporary and NOT permanent (Ch.05 Quiz Q1); use 'nmcli connection modify <con> +ipv4.routes "<subnet> <gw>"' for persistent static routes.**
- **In NetworkManager, a device (NIC) can have multiple connections (profiles), but only ONE connection can be active at a time; run 'nmcli con up <name>' after modifying a connection.**
- **tracepath measures hop count, per-hop RTT, and Path MTU (pmtu); ss (-talnp) is faster than netstat because it queries socket data directly from the kernel.**
