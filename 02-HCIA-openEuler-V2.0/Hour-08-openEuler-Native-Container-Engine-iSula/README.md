# ⏱️ Hour 08: openEuler Native Container Engine iSula (iSulad)
**Pillar:** HCIA-openEuler V2.0 (Operating System & Cloud-Native iSula)  
**Official Material Reference:** Chapter 07 (pp. 382–441)  
**Pacing:** 60 Minutes (4 × 15-Minute Active Learning Sprints)

Master Linux container kernel primitives (6 Namespaces for resource isolation and `cgroups` for resource limitation), explore the C/C++ architecture and performance advantages of openEuler's native `iSula` (`iSulad`) engine, install/configure `iSulad` and run container lifecycle commands across all 4 container states (`Created`, `Up`, `Paused`, `Exited`), configure CNI bridge networking and `-v` persistent storage, and manage UnionFS (`AUFS`, `OverlayFS`) layered container images.
