# Hour 08: Basic O&M of Computing Products: iBMA, iBMC, Smart Provisioning, FusionDirector, eSight, SmartKit & eService
**Pillar:** HCIA-Computing V3.0 (Kunpeng & Server Ecosystem)  
**Official Material Reference:** Chapter 06 (pp. 351–443)  
**Pacing:** 60 Minutes (4 × 15-Minute Active Learning Sprints)

Master the complete Huawei Computing O&M ecosystem: O&M evolution (Manual/Scripts -> Tools -> Automation -> Intelligence), In-band (iBMA + BOB) vs. Out-of-band (iBMC + Smart Provisioning) single-node management, Centralized management via FusionDirector (5 Intelligent Features) and eSight (IF1–IF5 interfaces & batch specs), Local O&M via SmartKit, and Remote O&M via eService (Call Home).
