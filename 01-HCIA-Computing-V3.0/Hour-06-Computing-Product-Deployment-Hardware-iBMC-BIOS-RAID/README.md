# Hour 06: Computing Product Deployment: Equipment Room, iBMC, BIOS & RAID Configuration
**Pillar:** HCIA-Computing V3.0 (Kunpeng & Server Ecosystem)  
**Official Material Reference:** Chapter 05 Part 1 (pp. 284–325)  
**Pacing:** 60 Minutes (4 × 15-Minute Active Learning Sprints)

Master data center equipment room layouts, cabinet/environmental/ESD standards, TaiShan 200 (2280) physical installation & power-on specs, default iBMC IP and user credentials, iBMC WebUI setup (firmware, NTP, VNC, SNMPv1/v2/v3), Remote Virtual Console (Private vs. Shared), BIOS POST & PXE configuration, and RAID/JBOD setup.
