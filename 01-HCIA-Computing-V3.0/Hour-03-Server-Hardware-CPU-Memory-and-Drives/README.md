# ⏱️ Hour 03: Server Hardware Architecture: CPU, Memory, Mainboard & Storage Drives
**Pillar:** HCIA-Computing V3.0 (Kunpeng & Server Ecosystem)  
**Official Material Reference:** Chapter 03 Part 1 (pp. 130–158)  
**Pacing:** 60 Minutes (4 × 15-Minute Active Learning Sprints)

Deep-dive into TaiShan 200 (2280) internal hardware components, CPU architecture (Control Unit, ALU, Registers, Cache), Kunpeng 920 processor SKUs, SRAM vs. DRAM/ROM, 8-channel DIMM population rules, S920X00 mainboard, front/rear panel layouts, and SATA/SAS/NL-SAS/SSD/NVMe drive technologies.
