# Hour 05: Huawei Kunpeng Processors, TaiShan Servers, openEuler/openGauss & HPC
**Pillar:** HCIA-Computing V3.0 (Kunpeng & Server Ecosystem)  
**Official Material Reference:** Chapter 04 (pp. 227–283)  
**Pacing:** 60 Minutes (4 × 15-Minute Active Learning Sprints)

Master Huawei's Kunpeng computing industry: chip evolution (1991 ASIC to Kunpeng 920 7nm), SoC/Chip/Die/Cluster/Core hierarchy, HCCS inter-chip interconnect, Kunpeng Accelerator Engine (KAE), TaiShan 100 vs. TaiShan 200 (2280/5280/2480/1280/2280E) specifications, openEuler (A-Tune, iSulad), openGauss (1.5M tpmC, NUMA, Mulan PSL v2), and Kunpeng HPC.
