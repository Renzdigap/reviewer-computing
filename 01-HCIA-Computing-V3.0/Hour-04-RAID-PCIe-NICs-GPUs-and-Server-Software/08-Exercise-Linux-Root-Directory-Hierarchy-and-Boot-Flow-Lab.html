Hands-On Lab: Linux Root Directory Inspection & OS Call Chain

🛠️ PRACTICAL LAB SCENARIO

Inspect the openEuler root filesystem (/) and verify the exact standard directories for configuration files, peripheral devices, temporary mounts, and third-party software packages.

📋 Instructions

  • 1Run ls / to list the top-level directories under the root filesystem.
  • 2Set CONFIG_DIR to '/etc', DEVICE_DIR to '/dev', TEMP_MOUNT_DIR to '/mnt', and THIRD_PARTY_APP_DIR to '/opt'.
  • 3Set POSIX_IEEE_STANDARD to 'IEEE 1003'.
