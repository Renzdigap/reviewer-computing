# ⏱️ Hour 05: Database & Object Management (MOT, Tablespaces, Users/Roles, Backup/Export)
**Pillar:** HCIA-openGauss V2.0 (Enterprise Relational Database & GaussDB)  
**Official Material Reference:** Chapter 04 (pp. 273–351)  
**Pacing:** 60 Minutes (4 × 15-Minute Active Learning Sprints)

Master the openGauss logical object hierarchy (Databases, Schemas, Tables, Views, Indexes, Transactions), configure Memory-Optimized Tables (MOT), manage Tablespaces and disk quota thresholds, administer Users, Roles, Account Validity/Locking, and Private (`INDEPENDENT`) Users, query System Catalogs/Views, and perform Data Import/Export (`COPY`, `\copy`, `gs_dump`, `gs_dumpall`, `gs_restore`, `VACUUM FULL`, `ANALYZE`).
