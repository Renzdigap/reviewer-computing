# Hour 07: SQL DDL Objects, Sequences, Operators & Built-in Functions
**Pillar:** HCIA-openGauss V2.0 (Enterprise Relational Database & GaussDB)  
**Official Material Reference:** Chapter 05 Part 2 (pp. 407–473)  
**Pacing:** 60 Minutes (4 × 15-Minute Active Learning Sprints)

Master DDL statements (`CREATE`, `ALTER`, `DROP`) for Databases (`template0` vs `template1`), Schemas (`AUTHORIZATION`, `SEARCH_PATH`), Tables & Constraints (`PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `CHECK`, `NOT NULL`, `PARTIAL CLUSTER KEY`), Partitioned Tables & Indexes (`LOCAL`, `GLOBAL`, `CONCURRENTLY`, `UNUSABLE`), Views & Sequences (including decremental sequences!), and Built-in Operators & Functions (Logical, Comparison, String, Arithmetic, Date/Time, Type Conversion, and Geometric).
