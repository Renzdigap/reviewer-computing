Hands-On Lab: Inspecting the Multi-Threaded gaussdb Process & Kernel Version

PRACTICAL LAB SCENARIO

Verify that openGauss runs as a single gaussdb process with multiple worker and background threads (unlike PostgreSQL's multi-process model) and check the openGauss version and incremental checkpoint setting.

Instructions

  • 1Step 1: Use ps ux | grep gaussdb to view the running gaussdb master process.
  • 2Step 2: Use ps -T -p 24209 to list the threads (SPID) inside the gaussdb process.
  • 3Step 3: Query the enable_incremental_checkpoint parameter using gsql -d postgres -p 5432 -c "SHOW enable_incremental_checkpoint;".
