# Hour 01: openGauss Overview & Database Fundamentals
**Pillar:** HCIA-openGauss V2.0 (Enterprise Relational Database & GaussDB)  
**Official Material Reference:** Chapter 01 (pp. 1–72)  
**Pacing:** 60 Minutes (4 × 15-Minute Active Learning Sprints)

Master the foundational concepts of databases (Data, DB, DBMS, DBS), trace the three stages of data management evolution and classical data models, evaluate ACID transaction semantics and multi-node database architectures, and understand openGauss positioning, architectural advantages over PostgreSQL, technical specifications, and client APIs.
