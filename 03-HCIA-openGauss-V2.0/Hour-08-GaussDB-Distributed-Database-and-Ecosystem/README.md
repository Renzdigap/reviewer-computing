# Hour 08: GaussDB Enterprise Distributed Database & Cloud Ecosystem
**Pillar:** HCIA-openGauss V2.0 (Enterprise Relational Database & GaussDB)  
**Official Material Reference:** Chapter 06 (pp. 474–531)  
**Pacing:** 60 Minutes (4 × 15-Minute Active Learning Sprints)

Understand the positioning and differences between open-source openGauss and commercial distributed GaussDB, master GaussDB's high-availability topologies (1+1, 1+2, Intra-City Active-Active, 3-AZ Multi-Active, Two-Site Three-Center 3DC Geo-Redundant DR, Remote DR), memorize the roles of all distributed components (CN, DN, GTM/GTM-Lite/GTM-Free, CM/CMS, OM, ETCD), and apply the Huawei Cloud database tool suite (DAS, DRS, UGO, CTS, CES, DBSS).
