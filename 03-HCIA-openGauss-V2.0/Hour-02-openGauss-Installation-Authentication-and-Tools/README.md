# Hour 02: openGauss Installation, Authentication & O&M Tools
**Pillar:** HCIA-openGauss V2.0 (Enterprise Relational Database & GaussDB)  
**Official Material Reference:** Chapter 02 (pp. 73–130)  
**Pacing:** 60 Minutes (4 × 15-Minute Active Learning Sprints)

Master the three openGauss deployment modes, hardware/software prerequisites, OS preparation steps, single-node and enterprise installation/uninstallation workflows, client authentication (`pg_hba.conf`, `gs_guc`), `gsql` local/remote connections, and the complete suite of openGauss client and server O&M tools.
