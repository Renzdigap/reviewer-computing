# ⏱️ Hour 06: SQL Basics — Classification, Data Types, DQL, Joins & DML
**Pillar:** HCIA-openGauss V2.0 (Enterprise Relational Database & GaussDB)  
**Official Material Reference:** Chapter 05 Part 1 (pp. 352–406)  
**Pacing:** 60 Minutes (4 × 15-Minute Active Learning Sprints)

Master the 4 SQL statement categories (DDL, DML, DCL, DQL), openGauss data types and exact byte sizes (`TINYINT`, `SMALLINT`, `INTEGER`, `BIGINT`, `CHAR`, `VARCHAR`, `CLOB`, Date/Time, Binary, Boolean), DQL filtering (`WHERE`, `BETWEEN`, `AND`/`OR`/`NOT`), sorting (`ORDER BY` column names/positions, `NULLS FIRST/LAST`), pagination (`LIMIT`/`OFFSET`), Joins (`INNER`, `LEFT`, `RIGHT`, `FULL`, Cartesian product), and DML (`INSERT`, `ON DUPLICATE KEY UPDATE`, `UPDATE`, `DELETE`).
